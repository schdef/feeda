# Security Policy

## Supported Versions

Security updates are provided for the latest releases on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Feeda seriously. If you discover a potential vulnerability, please help us protect our users by responsibly disclosing it.

### How to Report

- **GitHub Security Advisory**: Open a private draft security advisory at `https://github.com/schdef/feeda/security/advisories/new`.
- **Direct Contact**: If GitHub advisories are unavailable, please contact the maintainer directly via GitHub profile contact details.

Please include as much of the following information as possible:
- Detailed steps to reproduce the vulnerability or a minimal Proof of Concept (PoC).
- Potential impact and severity.
- Affected endpoints, parameters, or configurations.

### Disclosure Process

1. We will acknowledge receipt of your report within 48 hours.
2. We will validate the issue and coordinate a fix in a private branch.
3. Once a patch is ready and tested, we will release an update and credit the reporter.

Please do not open public GitHub issues for undisclosed security vulnerabilities.
